# Money Made Simple

The website for **Money Made Simple**: free financial calculators that show what your money decisions really cost, unlocked with an email address, plus a blog explaining the thinking behind each calculator.

- **Stack:** [Astro](https://astro.build) (static site, Markdown blog), TypeScript, a Cloudflare Pages Function for signup, MailerLite for email.
- **Start here:** [docs/GUIDE.md](docs/GUIDE.md) — how to run it, add posts and calculators, and go live.
- **Design screenshots:** [docs/design/](docs/design/)

```bash
npm install
npm run dev
npm test
```
